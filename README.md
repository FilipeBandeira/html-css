# Estudos de HTML e CSS

Exercícios realizados ao longo do curso de HTML5 e CSS3.

## Organização

- `EXERCÍCIOS/`: Exemplos e desafios por assunto: textos, links, imagens, tabelas, formulários, iframe e media queries.

## Como estudar e executar

Requisitos: navegador moderno. Para servir os exemplos localmente, Python 3.

```sh
git clone https://github.com/FilipeBandeira/html-css.git
cd html-css
python3 -m http.server 8000
```

Abra `http://localhost:8000/EXERCÍCIOS/EX001/index.html` ou navegue pelas pastas no servidor. Leia o código de cada exemplo, execute-o e compare o comportamento com o assunto estudado.

## Escopo

Alguns exercícios incluem recursos externos ou formulários demonstrativos. O servidor estático não executa PHP. Este repositório preserva a trajetória de aprendizado e os créditos dos materiais originais.
